# GetReadyToMassacred — Releases

Setups et fichier de mise à jour (`getreadytomassacred-update.json`) de GetReadyToMassacred, banc d'analyse Mythique+ pour un groupe de cinq. Le code source est dans un dépôt privé.

Installer : télécharger `GetReadyToMassacred-Setup-V.X.Y.Z.exe` de la dernière Release, par utilisateur, sans droits d'administrateur. SmartScreen peut avertir (exe non signé) : « Informations complémentaires » → « Exécuter quand même ».
